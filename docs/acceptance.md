# 受け入れ条件の確認結果

確認日: 2026-10-23
環境: macOS、Apple M4、Chromium（Playwright 1.64、ANGLE Metal）、1360×840 と 390×780。
サンプル: `samples/math.v1.json`（37 ノード、42 関係、最大 4 階層）。

自動確認は `npm test`（単体 29 件）と `npm run e2e`（実ブラウザ 12 件、各テストの動画を `test-results/` に保存）。
操作動画は `npm run tour` で録れる。

## 探索

| 条件（構想書 §8.2, §11） | 結果 | 確認方法 |
| --- | --- | --- |
| ノードを選ぶと中央へ滑らかに移り、説明が出る | 達成 | e2e: 選択後のノード位置がパネルを除いた領域の中心から 40px 以内 |
| 説明パネルが選択ノードを隠さない | 達成 | 投影の中心をパネルの幅（狭い画面では高さ）の半分ずらす。e2e: 幅 1360 と 390 の両方 |
| 入れ子への接近と、内部グラフの出現が一連の動作に感じられる | 達成（調整の余地あり） | 子の階層は親の球の内側にあり、カメラが近づくと球が膜のように薄れ、子が中心から広がって現れる。進み具合はカメラ距離から計算 |
| 戻ると元の階層・選択・視点に戻る | 達成 | e2e: 二階層入って戻り、選択と画面上の位置（浮遊分の誤差 16px 以内）を確認 |
| パンくずで現在地が分かり、上の階層へ移れる | 達成 | e2e |
| 別の枝への接続を発見し、移動し、戻れる | 達成 | 選択時にポータル（相手の名前と所属）を出す。パネルの「つながり」にも「別の枝」として出る。e2e: ポータルとパネルの両方から移動し、Esc で元の場所へ |
| 閉じた階層へのリンクの存在と相手が分かる | 達成 | ノードのラベルに「外部 N」、選択時にポータル。分野を選ぶと内部から外へ出る関係も「内部の〇〇から」と出る |
| 連打、遷移中の戻る・再選択でカメラと説明が別のノードを指さない | 達成 | 説明と現在地は常に意図（移動先）を表示し、シーンはそこへ収束する。入る途中の戻るは同じ遷移の逆再生、移動途中の行き先変更は現在の一段を短縮して続ける。e2e: 入る途中の Esc、移動途中の Esc と行き先変更、Enter/Esc の 4 往復 |
| 控えめな常時アニメーション | 達成 | 浮遊（振幅 4）、発光の呼吸、分野の輪の回転。描画上のずらしだけで、配置と保存データは変えない |
| アニメーション低減設定で操作できる | 達成 | 浮遊・呼吸・回転を止め、遷移を 260ms に短縮し、子の広がりを省く。e2e: `reducedMotion: reduce` で出入り |
| 表示サイズ変更に対応 | 達成 | ResizeObserver で投影とパネルの領域を更新。390px 幅では説明が下に出る |
| 日本語のラベルと説明が読みやすい | 達成 | ラベルは DOM で描き、画面上の大きさに合わせて縮尺と不透明度を変える。小さすぎる間は隠す |
| 長いラベル、空のグループ、循環する関連、複数階層の接続で破綻しない | 達成 | 長いラベルは折り返し、配置の箱も広がる（目視）。空の分野は e2e。関連の循環・前提の循環は単体テスト。4 階層をまたぐ移動は e2e |
| 同じ構造なら同じ配置、選択だけで再配置しない | 達成 | ELK にモデル順を考慮させ乱数の種を固定。選択では配置を計算し直さない。説明文の編集でも作り直さない |

性能（Apple M4 のヘッドレス Chromium、1280×760）: 待機・入る遷移・4 階層の移動のいずれも約 61fps。
ELK の配置は一階層 15〜30ms（Worker 上、構造が同じならキャッシュを使う）。大規模なツリーは未計測。

## 人が触って調整する項目

自動では判断できない。`/?tune` の調整パネルで実行中に変え、「値をコピー」で `src/tuning.ts` へ反映する。

- 入る速さ（初期値 900ms、`outCubic`）。計測では行程の半分（対数距離）に約 210ms、親が消え終わるのが約 500ms。
- 選択の移動（550ms、`outQuart`）と、選択時の寄り具合。
- 子が現れるタイミングとずれ（`innerAppear`、`innerStagger`）、広がり始めの大きさ。
- 奥行きのばらつき、カメラの傾き、浮遊と発光の量。
- 何階層もまたぐ移動の一段あたりの時間（下限 380ms）。

## 制約と未実装

- 個人の学習記録（時間・点数・達成日）の入力と表示はない。実績の定義は説明パネルに表示するだけで、編集画面はない。
- 元に戻す（undo）はない。
- キャンバス上のノードはキーボードで選べない。パネル・パンくず・ボタンはキーボードで操作できる。
- タッチではドラッグで移動できるが、ピンチでの拡大・縮小はない。
- ポータルの位置はノードの中心だけを避けるので、折り返した長いラベルの近くに重なることがある。
- 何百ノードもある階層、何千ノードのツリーでの性能と見やすさは確かめていない。
- 本番ビルドの JavaScript は約 960KB（gzip 264KB）。three.js と React が大半で、分割していない。
- 取り込み元の更新の反映、別ツリーの同じスキルの同一視、公開・共有の仕組みはない（構想書 §8.4 の範囲外）。
